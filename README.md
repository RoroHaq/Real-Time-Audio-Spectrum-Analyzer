# Real-Time-Audio-Spectrum-Analyzer
circuit that visualizes 3 filters via a dashboard from a phone audio input

## Theoreitcal Notes behind this

For this project, I will essentially be creating 3 circuits in parallel, them being 

- Low Pass Bass Filter (20-250Hz)
- Band-Pass Filter (250-3000Hz)
- High-Pass Filter (3000-16000Hz)

It will be created in parallel of one another from the main signal source, powered by a jack input.
